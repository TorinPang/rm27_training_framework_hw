# SPI通信

## SPI通信简介

SPI是 Serial Peripheral interface 的缩写，意思是串行外围设备接口。
SPI是一种高速的、全双工、同步的通信总线，在芯片管脚上只占用四根线，节约管脚，节省空间。

### 主从模式

SPI有主、从两种模式，一个SPI通讯系统需要包含恰好一个主设备与至少一个从设备。

* 主设备：提供时钟的设备为主设备
* 从设备：接收时钟的设备为从设备

SPI接口的读写操作，均由主设备发起，当有多个从设备时，通过给的片选信号进行管理。

**SPI是全双工且SPI没有定义速度限制，一般的实现通常能达到甚至超过 10Mbps**

### SPI信号线

SPI接口一般使用四条信号线通信：SDI（数据输入），SDO（数据输出），SCK（时钟），CS（片选）。

* MISO：主设备输入/从设备输出引脚。该引脚在从模式下发送数据，在主模式下接受数据。
* MOSI：主设备输出/从设备输入引脚。该引脚在主模式下发送数据，在从模式下接收数据。
* SCLK：串行时钟信号，由主设备产生。
* CS/SS：从设备片选信号，由主设备控制，它饿功能是用来作为“片选引脚”，也就是选择指定的从设备，让主设备可以单独地与特定从设备通讯，避免数据线上的冲突

### SPI设备选择

SPI是单主设备通信协议，只有总线中的一个中心设备能发起通信。当SPI主设备想读/写从设备的时候，就首先拉低从设备对应的SS线（SS是低电平有效），然后就发送工作脉冲到时钟线上。在相应脉冲时间上，主设备可以把信号发到MOSI实现写，也可以接收来自MISO的信息实现“读”，如下。

## SPI数据的发送与接收

SPI主机与从机都有一个串行移位寄存器，主机通过向它的SPI串行寄存器写入一个字节来发起一次传输。

1. 首先拉低对应的SS信号线，表示与该设备进行通信。
2. 主机通过发送SCLK时钟信号，来告诉从机写数据或读数据
3. 主机将发送的数据写到发送数据缓存区，缓存区经过移位寄存器，串行移位寄存器通过MOSI信号线将字节一位一位地移出去传送给主机，同时MISO接口接收到的数据经过移位寄存器一位一位地移到接收混存取。
4. 从机也将自己地串行移位寄存器中地内容通过MISO信号线返回给主机，同时通过MOSI数据线接收主机发送的数据，这样两个移位寄存器中的内容就被交换了。

SPI没有读和写的说法，外设的写操作与读操作是同步完成的。如果只进行写操作，主机只需要忽略接收到的字节；反之，若主机要读取从机的一个字节，就必须发送一个空字节来引发从机的传输。就是说，发一个数据必然收到一个数据，收一个数据也要先发一个数据。

### SPI通信的四种时钟模式

**SPI的四种模式，就是设置SCLK时钟信号线的哪种信号为有效信号**

SPI通信有4种不同的操作模式。从设备在出厂时就配置为某种模式，不能改变；但我们的通信双方必须时在同一模式下，所以我们可以对我们主设备的SPI模式进行配置，通过CPOL（时钟极性）和CPHA（时钟相位）来控制我们主设备的通信模式。

**时钟极性（CPOL）**定义时钟空闲状态电平：

* CPOL = 0，表示当SCLK=0时处于空闲态，所以SCLK处于高电平时就是有效状态
* CPOL = 1，表示当SCLK=1时处于空闲态，所以SCLK处于低电平时就是有效状态

**时钟相位（CPHA）**定义数据的采集时间。

* CPHA = 0，在时钟的第一个跳变沿进行数据采样，在第2个边沿发送数据。
* CPHA = 1，在时钟的第二个跳变沿进行数据采样，在第1个边沿发送数据。

它们的区别是定义了在时钟脉冲的哪条边沿转换（toggles）输出信号，哪条边沿采样输入信号，还有时钟脉冲的稳定电平值（就是时钟信号无效时是高还是低）。每种模式由一对参数刻画，它们称为时钟极（clock polarity）CPOL与时钟期（clock phase）CPHA。

### SPI的通信协议

主从设备必须使用相同的工作模式————SCLK、CPOL和CPHA，才可以正常工作。如果有多个从设备，并且使用了不同的工作模式，主设备就必须在读写不同从设备时修改对应设置。以上就是总线协议的主要内容。

### SPI的三种工作模式

#### 运行模式(Run Mode)

这是基本的操作模式

#### 等待模式(Wait Mode)

SPI工作在等待模式是一种可配置的低功耗模式。在这个模式下，CPU不直接干活，但有些外设仍在工作，而这些外设可以通过中断重新唤醒CPU

#### 停止模式(Stop Mode)

为了降低功耗，SPI在停止模式是不活跃的。如果SPI配置为主机，正在进行的传输会停止，但是在CPU进入运行模式后会重新开始。如果SPI配置为从机，会继续接受和发送一个字节，这样就保证了从机与主机同步。
